# 3. VISUAL DESIGN DIRECTION

The overall visual direction must be:

- Minimal.
- Warm.
- Refined.
- Editorial.
- Sophisticated.
- Premium.
- Timeless.

The website should feel like a contemporary boutique interior-design studio or a high-end architecture and interiors editorial.

## Colour palette

Use the following colour direction:

- Primary background: Milk white / warm white.
- Secondary background: Soft beige.
- Supporting colour: Warm tan.
- Neutral colour: Light taupe.
- Accent: Muted champagne / subtle light gold.
- Text: Dark warm grey / charcoal.
- Occasional accent: Very subtle warm brown.

Gold must never dominate the interface. Use it only for small accents, fine lines, subtle hover states and selected UI elements.

Avoid bright colours, heavy gradients, saturated backgrounds and unnecessary decorative elements.

## Typography

Use an elegant editorial-style serif font for:

- Main headings.
- Hero statements.
- Project names.
- Section headings.
- Important brand statements.

Use a clean contemporary sans-serif font for:

- Navigation.
- Paragraphs.
- Buttons.
- Forms.
- Supporting information.

Suggested font combinations:

- Cormorant Garamond + Manrope.
- Playfair Display + Inter.
- DM Serif Display + DM Sans.

Choose the combination that produces the most refined and readable result.

Typography should feel luxurious without sacrificing readability.

## Layout

- Use generous whitespace.
- Maintain consistent alignment and spacing.
- Use large visual sections.
- Prefer editorial compositions over conventional card-based layouts.
- Avoid excessive boxes, borders and rounded cards.
- Use subtle separators where necessary.
- Keep the overall experience uncluttered.

The interior photographs must remain the primary visual attraction.
